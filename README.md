# Student–Teacher Appointment Booking System

A simple web application that allows students to book appointments with teachers.

## Features

- Student and teacher login and registration.
- Students can book appointments with teachers.
- Teachers can view appointment requests.
- Teachers can approve or reject appointments.
- Firebase authentication and database integration.

## Technologies Used

- HTML
- CSS
- JavaScript
- Firebase

## How to Run

1. Download or clone the project.
2. Open the project folder in Visual Studio Code.
3. Set up your Firebase configuration.
4. Install the Live Server extension.
5. Open `index.html`.
6. Right-click and select **Open with Live Server**.

## Firebase Setup

1. Open the `js` folder.
2. Copy `firebase-config.example.js`.
3. Rename the copied file to `firebase-config.js`.
4. Add your Firebase project configuration.
5. Make sure `firebase-config.js` is listed in `.gitignore`.

## Project Purpose

This project was created to make student–teacher appointment booking easier and faster.
